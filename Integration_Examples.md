# EmotiBit Integration Examples

Explore how researchers, developers, and creators combine EmotiBit with other hardware and software to build interactive applications.

## Featured Integrations

| Project | Technology | Application |
|---|---|---|
| EmoMirror | TouchDesigner + Python/ML | Interactive physiological visualization |
| Pneunocchio | Pneumatic controller | Physiologically responsive wearable |

## EmoMirror

**Integration:** EmotiBit + TouchDesigner + Python/ML

**Overview:** Uses physiological signals from EmotiBit to generate interactive visual feedback.

**How EmotiBit is used:** Real-time physiological signals are processed and translated into visual representations.

**What You Can Learn:**
- How EmotiBit's real-time physiological data can be integrated with TouchDesigner and Python.
- How physiological signals can be transformed into interactive visual feedback.
- Where to find technical resources for exploring similar software integrations.

**Resources:**
- Original project repository: [Original EmoMirror GitHub repository](https://github.com/grenmango51/EmoMirror)
- Integration guide: [EmotiBit Integration Guide](https://github.com/grenmango51/EmoMirror/blob/main/EmotiBit_Guide.md)
- Creator credits: Thinh Bui, Thanh Hoai Anh Nguyen, and Vo Nhan

## Pneunocchio

**Integration:** EmotiBit + pneumatic controller + inflatable wearable

**Overview:** Transforms changes in physiological activity into physical movement through an inflatable wearable.

**How EmotiBit is used:** Heart rate and electrodermal activity are monitored to trigger pneumatic inflation.

**What You Can Learn:**
- How heart rate and EDA signals can be used to trigger physical responses through external hardware.
- How physiological baselines and thresholds can be incorporated into interactive wearable systems.
- What practical limitations to consider when connecting EmotiBit to pneumatic hardware.

**Resources:**
- Original research paper: [Pneunocchio (UIST 2023)](https://doi.org/10.1145/3586182.3616651)
- Detailed technical research: [Designing Pneumatic Wearables — PhD Thesis (2026)](https://exertiongameslab.org/wp-content/uploads/2026/06/designing_pneumatic_wearables_phd.pdf) — See Chapter 5 for Pneunocchio's design, implementation, and field study.
- **Researcher credits:** Aryan Saini, Srihari Sridhar, Aarushi Raheja, Rakesh Patibanda, Nathalie Overdevest, Po-Yao (Cosmos) Wang, Elise van den Hoven, and Florian "Floyd" Mueller
- **Research affiliations:** Exertion Games Lab (Monash University), University of Technology Sydney, and Eindhoven University of Technology
